# Подарки для неё 💜

Игра на 6 дней: каждый день — новое испытание, за победу — кручение колеса фортуны со скрытыми подарками. Подарок дня открывается и убирается из колеса.

Вместе с ней игру проходит **малыш Грутик**: в первый день Сонечка сажает семечко в горшочек, и с каждым днём Грутик растёт и подбадривает её в реплике-пузырьке над игрой.

## Как пополнить пул подарков (в любой момент!)

1. Открой `gifts.js`
2. Добавь или отредактируй объект в массиве `GIFT_POOL`:
```js
{
  id: "g7",                      // уникальный
  title: "Серёжки",              // название подарка
  text: "Маленькая радость, жду когда надену на тебя",  // описание
  photo: "photos/gift7.jpg",     // фото (папка photos/)
  link: "https://ozon.ru/..."    // ссылка на покупку
}
```
3. Положи фото в `photos/` (картинку можно, например, скачать со страницы покупки).
4. Запушь изменения — подарок появится в колесе как новый скрытый «?» (если дни ещё идут).

Подсказки:
- `title`, `text` — обязательные; `photo` и `link` — можно пустые.
- Подарок выбирается случайно среди ещё не выпавших. После получения его `id` сохраняется в прогрессе, поэтому второй раз он не появится.
- Количество дней игры задаётся в `SITE_CONFIG.days` (по умолчанию 6).
- Если подарков в пуле больше, чем дней — она получит столько, сколько дней, остальные останутся секретом.
- Для первого уровня добавь 12 фотографий `photos/01.jpg`–`photos/12.jpg`. Каждая появится на двух карточках. Отдельную центральную фотографию положи в `photos/center.jpg`; пути можно изменить в `SITE_CONFIG.memoryPhotos` и `SITE_CONFIG.memoryCenterPhoto`.
- Для четвёртого дня положи портретную общую фотографию в `photos/couple.webp` или измени путь `SITE_CONFIG.couplePhoto`. «Протокол МЫ» состоит из трёх фаз: освобождение Грутика от щупалец, портретный пазл 3×4 без обрезки фотографии и плетение общей рамки из корней и симбиота.

## Как проверить самому

Открой `index.html` из папки или хости, добавив параметры:
- `?preview=3` — посмотреть день 3 (1–6), без сюжетных сцен
- `?stage=5` — просто нарисовать Грутика в стадии 5 (веном), чтобы проверить вид
- `?reset` — стереть весь прогресс и начать заново

## Как запустить для неё (GitHub Pages)

1. Зарегистрируйся/залогинься на https://github.com
2. Создай новый репозиторий `AdventGame` (New repository, Public)
3. В локальном проекте:
   - закинь в него файлы
   - `git add . && git commit -m "init" && git remote add origin <ссылка репозитория> && git push -u origin main`
4. В репозитории: Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save.
5. Через пару минут ссылка: `https://<твой-ник>.github.io/AdventGame/`

Открой ссылку с телефона и свято храни её никому не показывая — пусть откроет сама.

## Файлы

- `index.html`, `style.css` — страница и дизайн
- `app.js` — прогресс, дни, колесо, подарки, сюжет
- `games.js` — шесть испытаний: пары фотографий 5×5, Block Blast с перетаскиванием, звёздные нити, трёхфазный «Протокол МЫ», схема 4×4 и трёхфазный финал
- `grutik.js` — многослойный canvas-рендер Грутика, стадии роста и симбиоза с Веномом, анимации и реплики (`GRUTIK_LINES`)
- `gifts.js` — пул подарков (здесь редактируем!)
- `photos/` — фото подарков
